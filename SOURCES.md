# Nguồn và giấy phép

Các thư mục `vendor/` là bản sao cố định của nguồn công khai, không phải do repo này tự viết. Giữ nguyên giấy phép của từng nguồn trong thư mục tương ứng.

| Thành phần | Nguồn | Phiên bản / commit | Giấy phép |
|---|---|---|---|
| Impeccable, hai biến thể Codex/OpenCode | [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | tag `skill-v4.5.0`, commit `508d7e8955de3b3caf2d8676e85206723d41a887`, engine `0.1.11` | Apache 2.0; `vendor/impeccable/LICENSE`, `NOTICE.md` |
| 8 skill GSAP | [greensock/gsap-skills](https://github.com/greensock/gsap-skills) | `aed9cfd3277740755f6bfc1155c7aa645403b760` | MIT; `vendor/gsap/LICENSE` |
| Kho dữ liệu UI UX Pro Max | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | 2.13.0, `477bcb28c9812b385cb51a4605ddf30d7b2266e2` | MIT; `vendor/ui-ux-pro-max/LICENSE` |
| Taste v2 experimental | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | `b482f7a970abb98c4108d4a9f761e458c64cefc8` | MIT; `vendor/taste/LICENSE` |
| `threeui` skill | Skill hướng dẫn do bộ này viết; tham chiếu [MengTo/threeui](https://github.com/MengTo/threeui) | Bản trong repo | MIT của repo này |
| Hai skill tra cứu, script cài và tài liệu | Viết cho bộ này | Bản trong repo | MIT của repo này |

Repo này không chứa mã component ThreeUI, package GSAP, các model AI, token hay cấu hình cá nhân. Khi dùng ThreeUI trong một project, cài package chính thức theo nhu cầu và giấy phép của package đó.
